## 2. 暂缓项与改进建议存档（Argon 建议原文要点 + 处置备注）

- **S1 唯一行 ID（Line ID）替代字符串后缀匹配**：`RecentLine` 增自增 `id`，流式提交记录 `lastCommittedLineId`，精修替换按 id 精确定位。备注：当前 `endsWith` 两侧同源归一化、且 v0.10.6 补齐半句修正分支后链路自洽，风险已收敛；若后续出现匹配失败案例再启动此重构（届时连同磁盘行替换一并改造）。
- **S2 磁盘 I/O 移出主线程 + 行偏移覆写**：单线程 I/O 执行器承接 `transcriptFile` 全部写入；`replaceLastTranscriptLine` 用 `RandomAccessFile` 记录末行字节偏移做 O(1) 替换。备注：与 S1 一并做，避免两次结构性改动。
- **S3 `TranscriptBufferManager` 纯 Kotlin 抽取 + JUnit 单测**：把 `isNearDuplicate`/`recentLines` 滑窗/替换逻辑抽为不依赖 Context 的类。备注：有价值，随 S1 重构顺带抽取；单测框架引入（JUnit 依赖）单独评估。
- **S4 GitHub Issues/Release 追踪**：Commit Message 关联 Issue 编号、根因写 Issue。备注：属流程改进，涉及账号侧操作（建 Issue 为网页操作），由用户决定是否采用；本地等价物已有（docs/修复_*.md + HANDOVER）。
- **S5 LLM 请求主动取消**：AI 面板关闭时取消进行中的 HTTP 请求。备注：低优先级——超时已兜底，挂起窗口有限。
